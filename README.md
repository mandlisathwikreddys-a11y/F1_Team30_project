# F1_Team30 – Domain Name System (DNS) Simulation & Lookup

## 1. Project Description
This project implements and simulates a Domain Name System (DNS). It includes a Python-based DNS lookup mechanism and a simulation configuration to demonstrate how domain names are resolved to IP addresses.

## 2. Software & System Requirements
* **Programming Language:** Python 3.x
* **Development Tools:** VS Code / Packet Tracer
* **Operating System:** Windows / Linux / macOS

## 3. Repository File Structure
* `dns.py` - Core DNS lookup implementation source code
* `main.py` - Main execution file to run the project
* `README.md` - Project documentation and execution steps

## 4. Installation & Setup Procedure
1. Clone this repository or download the source files.
2. Ensure you have Python installed on your system.

## 5. Execution Steps
1. Open your terminal or command prompt in this directory.
2. Run the main file using the command:
   ```bash
   python main.py
   ```

## 6. Expected Results & Testing
* The script will prompt for a domain name and return the corresponding resolved IP address successfully.
